# Using Salience

Guides for reading and working from the context Salience brings together. The workflow pages are outlines ready for examples and screenshots.

- [Arrange tiles and pages](./tiles-and-pages) — make a workspace for the information you want to see.
- [Review a pull request](./review-a-pull-request) — follow the ticket, changes, conversation and checks.
- [Check a build](./check-a-build) — find the work behind a result and read the available details.
- [Prepare for stand-up](./stand-up) — review progress, blockers and work needing attention.
- [Code Graph](/docs/code-graph) — explore code relationships.
- [MCP server](/docs/mcp) — give an agent access to the same context.
