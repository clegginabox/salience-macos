# Features

These guides cover useful actions that sit alongside Salience's joined work views.

- [Project files and drag and drop](/docs/features/project-files) — keep files with a project and link them to work.
- [Timer](/docs/features/timer) — timebox work and keep a session history you can correct.
- [Clean up](/docs/features/clean-up) — find merged worktrees and branches ready for review.

For arranging the workspace and following work across tools, see [Using Salience](/docs/using/).
