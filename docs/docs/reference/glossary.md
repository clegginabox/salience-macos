# Glossary

Short definitions for the terms used throughout Salience. For a worked example, read [Concepts and terminology](/docs/concepts).

| Term | Meaning |
| --- | --- |
| Project | A local repository and the work context Salience gathers around it. |
| Connection | Access to a tool or service that supplies information to Salience. |
| Entity | An individual thing Salience knows about, such as a branch, ticket or build run. |
| Correlation | A relationship between entities, established from identifiers or inferred from conventions. |
| Unit of work | Related entities brought together as one piece of work. |
| Situation | Something Salience notices about work that may need attention. |
| Loudness | How prominently a situation is presented. |
| Tile | A view of information that can be placed on a page. |
| Page | A collection of tiles. |
| Layout | The arrangement of tiles on a page. |
| MCP | Model Context Protocol: the protocol compatible agents use to access Salience's context. |
